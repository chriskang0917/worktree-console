# 封存

- 「封存 <代號>」→ `console.mjs archive --repo "$REPO" <代號>`，輸出 `[代號] 已封存` 逐字轉貼。封存不關 session、不動 worktree，只是不上看板表格、待回覆清單與專注橫條；代號照樣能指揮、看詳情、關閉。紀錄存在 `archive.json`，重開仍在；worktree 關閉後自動清掉。同一台機器上 Orca 與 herdr 的中控台共用這份紀錄，各自只清自己那邊封存的（沒標來源的舊紀錄算 Orca 的），看不到另一邊的 worktree 不算 worktree 已關閉。被封存的 session 轉成 💬 或 🔐 時腳本自動解除封存（問題不能被藏起），轉成 ⏸ 仍保持封存。不做依天數或狀態的自動封存。
- 有 mods 時可用專注面板「封存」分頁的「取消封存」按鈕解除（見〈專注模式〉）。
