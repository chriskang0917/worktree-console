# 回覆習慣（你通常會回）

| 指令 | 用途 |
| --- | --- |
| `memory.mjs replay` | 用 `~/.worktree-console/` 現有紀錄重跑一次規則：各情境做法次數、選擇題照建議次數、認不出的回覆（筆數與原話） |
| `memory.mjs remember <字母>` | 使用者回「記住 <字母>」時跑：把提議的做法寫進 `memory.md` 並 commit，輸出 `[記憶] 已記住 …` |
| `memory.mjs decline <字母>` | 使用者回「不記 <字母>」時跑：不寫檔，同做法再 3 次才再問，輸出 `[記憶] 這次不記 …` |

輸出一律原樣貼。中控台不手改 `memory.md`、不自己判斷習慣；欄位內容全由腳本照搬使用者過去的回覆。

- **欄位**：只在待回覆清單最後一欄「你通常會回」，專注面板卡片不顯示；跟「建議」欄（子 session 自己給的）是不同來源。沒有習慣就是「—」。
- **情境**：⏸ 回覆完畢依 worktree 的 git 狀態分 A（有未 commit 改動）、B（已 commit、還沒合進 base）、C（已合進 base）；提問含「定稿」是 D、含「開始／開工」是 E；其他有建議的提問是選擇題；都不是（一次性設計題）不顯示。
- **學習來源**：使用者在中控台打的原話（中控台對話紀錄），不是展開後送進子 session 的長指令。同一 session 下次停下前送出的多則指令算一次回覆；剛做完的那則之後緊接的「關閉」也併進去。做法只認關鍵字：commit、rebase、升版、squash／合併、push、關閉／收工、定稿、開始／開工；rebase、升版是前置步驟，不算做法不同。其餘字記成「認不出」，`replay` 會列出。
- **短期**：最近 30 天同情境同做法滿 3 次，欄位顯示該做法，並問要不要記住，一律四行：`要記住這個習慣嗎？`／`(<字母>) <情境說明> 時，你 30 天內 <N> 次都回「<做法>」`／空行／`輸入「記住 <字母>」記下來，「不記 <字母>」略過`。有 mods 時只接在同情境的題目下面（面板不放）；沒有 mods 時接在待回覆清單最下面；看板（`board`）也帶。使用者回「記住 <字母>」→ 跑 `remember`；回「不記 <字母>」→ 跑 `decline`。不回就一直留著，直到回答或該情境改用別的做法。
- **長期**：存在 `~/.worktree-console/memory.md`，`## <字母> <說明>` 分段、每條一行 `- ` 開頭、行尾括號備註；不隨時間過期。之後在同情境回了不同做法，腳本刪掉那行並 commit，改回依短期次數顯示。使用者可直接打開手改：說明怎麼寫都行，只要留著關鍵字；沒有情境字母或沒有關鍵字的條目腳本不改不刪，只在看 `狀態` 時提示「memory.md 有 N 條看不懂」：沒有 mods 時接在看板（`board`）最下面，有 mods 時 mod 攔下 `狀態` 開面板的同時跳一則浮動通知；不跟著印題、不進待回覆清單與面板。
- **選擇題**：只顯示「最近 30 天 N 次有 M 次照建議」，不進長期記憶。
- 不呼叫任何外部 API。
